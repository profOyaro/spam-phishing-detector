# Example phishing test cases

1. Brand impersonation URL: `http://paypal-security-login.tk`
2. IP-address URL: `http://192.168.1.44/login`
3. Shortener: `https://bit.ly/urgent-bank-verify`
4. Suspicious attachment: `invoice.pdf.exe`
5. Macro document: `payment_details.docm`
6. Free-mail abuse: `Microsoft Security <security-alert@gmail.com>`
7. Header failures: `spf=fail`, `dkim=fail`, `dmarc=fail`
8. OCR text: screenshot containing `Your account is suspended. Verify password now.`
